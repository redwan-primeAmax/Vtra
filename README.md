# 🎬 AutoDubber - Automated Video Dubbing Pipeline (English to Bengali)

**AutoDubber** একটি পাইথন-ভিত্তিক ওপেন-সোলাইজড ভিডিও ডাবিং প্ল্যাটফর্ম, যা ইংরেজি ভিডিওকে সুনির্দিষ্ট টাইম-সিঙ্কসহ প্রাকৃতিকভাবে বাংলা ব্যাকগ্রাউন্ড ও ভয়েস-ওভারে রূপান্তর করে।

এটি **Google Colab (T4 GPU / 12GB VRAM)** এবং লোকাল এনভায়রনমেন্টে নির্বিঘ্নে চলার জন্য অপটিমাইজ করা। এটি যেকোনো ইনপুট ভিডিও ফরম্যাট (যেমন: `.webm`, `.mkv`, `.mov`) স্বয়ংক্রিয়ভাবে প্রসেস করে ইউনিভার্সাল প্লেব্যাক-ফ্রেন্ডলি `.mp4` এক্সপোর্ট প্রদান করে।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

- 🔍 **ইনপুট অটো-হ্যান্ডলিং:** `.webm`, `.mkv`, `.avi` সহ যেকোনো ফরম্যাটের ইনপুট অটো-ডিটেক্ট করে এবং ব্যাকগ্রাউন্ডে প্রসেস করে।
- 🎶 **ভয়েস ও ব্যাকগ্রাউন্ড স্প্লিটিং:** `Demucs` ব্যবহার করে ব্যাকগ্রাউন্ড মিউজিক (BGM) অক্ষত রেখে মূল কণ্ঠ আলাদা করে।
- ⏱️ **টাইমস্ট্যাম্পসহ এসটিটি:** `faster-whisper` দিয়ে শব্দ ও বাক্যভিত্তিক নিখুঁত টাইমস্ট্যাম্প তৈরি।
- 🌐 **প্রাকৃতিক বাংলা অনুবাদ:** `NLLB-200` মডেল দিয়ে বাক্যের ভাবানুবাদ।
- 🗣️ **ন্যাচারাল ভয়েস জেনারেশন:** `Edge-TTS` দিয়ে প্রাকৃতিকভাবে শুনা যায় এমন বাংলা ভয়েস তৈরি।
- ⏳ **টাইম-স্ট্রেচিং ও লিপ-সিঙ্ক (Precision Sync):** মূল স্পিকারের কথার গতি অনুযায়ী বাংলা কণ্ঠের স্পিড স্বয়ংক্রিয়ভাবে টিউন করার প্রযুক্তি।
- 📺 **ইউনিভার্সাল আউটপুট:** H.264/AAC কোডেক কনফিগারেশনে `.mp4` এক্সপোর্ট, যা যেকোনো ডিভাইসে বা ব্রাউজারে প্লে হয়।
- ⚡ **VRAM অপটিমাইজেশন:** ধাপ শেষে ক্যাশ মেমোরি ক্লিয়ারেন্সের মাধ্যমে CUDA Out-of-Memory এরর প্রতিরোধ।

## 📁 প্রজেক্ট আর্কিটেকচার (Project Structure)

```text
auto_dubber/
│
├── config/
│   └── settings.py          # VRAM, মডেল নির্বাচন, FFmpeg ও জিপিইউ প্যারামিটার
│
├── inputs/                   # ইনপুট ভিডিও রাখার জায়গা (.webm, .mp4, .mkv ইত্যাদি)
├── outputs/                  # ফাইনাল ইউনিভার্সাল H.264 MP4 ভিডিও সেভ হবে
├── temp/                     # প্রসেসিং সাময়িক ফাইল (অটো-ক্লিনড)
│
├── modules/
│   ├── input_handler.py      # ইনপুট স্ক্যান ও .webm থেকে .mp4 অটো-কনভার্সন
│   ├── audio_sep.py          # Demucs দিয়ে Vocal ও BGM পৃথকীকরণ
│   ├── stt_engine.py         # faster-whisper (English STT + Timestamps)
│   ├── translator.py         # NLLB-200 (English -> Bengali Translation)
│   ├── tts_engine.py         # Edge-TTS (Bengali Audio Generation)
│   ├── time_sync.py          # Time-Stretching & Lip-sync Alignment
│   └── exporter.py           # FFmpeg Universal MP4 Merger
│
├── utils/
│   ├── gpu.py                # CUDA Memory Management (12GB VRAM Optimization)
│   └── logger.py             # রঙিন ও বিস্তারিত রিয়াল-টাইম টার্মিনাল লগিং
│
├── main.py                   # ◄── মাস্টার এন্ট্রি পয়েন্ট
├── requirements.txt           # লাইব্রেরি ডিপেনডেন্সি তালিকা
└── setup.py                   # প্যাকেজ সেটআপ ফাইল
